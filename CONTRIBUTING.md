# Contributing

This repository is a **mirror**. The pack is developed inside CraterView's platform repository,
alongside the API it calls, and copied here whenever a version is released. Every file outside
`.github/` is generated by that copy, so a pull request opened here cannot be merged as it is.

- **Issues are the right channel and they are read.** Bug reports, missing features and unclear
  documentation are all welcome.
- **A pull request is welcome as a proposal.** It says exactly what you would change. It is ported
  upstream with attribution, and closed when the release carrying it goes out.
- **Security reports do not belong in an issue.** Mail security@craterview.ai instead.
